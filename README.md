
# SOC Alert Monitoring & Investigation Tool

## Project Overview
A Python-based security monitoring tool designed to analyze system information, monitor common network ports, and identify suspicious login activities.

## Features
- System hostname and IP address detection
- Private IP identification
- MAC address information
- Common port monitoring
- Domain name resolution
- Failed login attempt analysis
- Linux-based security investigation

## Technologies Used
- Python
- Linux
- Bash Commands
- Git
- GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/soc-alert-monitor.git
```

Navigate to the project directory:

```bash
cd soc-alert-monitor
```

Run the application:

```bash
python3 main.py
```
